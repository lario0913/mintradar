# MintRadar interface prototype

A responsive front-end prototype with an editorial dark-green visual identity, acid-lime signal colour, animated radar sweep, ticker and responsive project discovery.

## Run locally
From this directory, run `npx serve .` and open the local URL.

## What's interactive
- Sidebar navigation between Overview, Discover, WL Radar, MintWatch, Saved and Submit views
- Search and filter project cards by network and opportunity status
- Responsive mobile navigation drawer
- Demo save/sign-in feedback toasts

## Important
All NFT project names, prices and dates are illustrative sample data, not verified live listings. Authentication, persistent watchlists, notifications, submissions and live project feeds are not connected yet.
